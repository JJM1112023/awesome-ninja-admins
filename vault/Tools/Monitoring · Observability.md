# Monitoring/Observability

13 curated tools. Pillar: [[Tool Arsenal]] · Up: [[Home]]

## System Monitoring

- [btop](https://github.com/aristocratos/btop) — beautiful terminal resource monitor for CPU, memory, disks, network, and processes
- [Gatus](https://gatus.io/) — automated service health dashboard driven by configuration
- [glances](https://nicolargo.github.io/glances/) — cross-platform, real-time system monitoring tool written in Python
- [Grafana](https://grafana.com/) — analytics and interactive visualization platform for metrics, logs, and traces
- [htop](https://htop.dev/) — interactive process viewer, the classic top replacement
- [Netdata](https://www.netdata.cloud/) — real-time, per-second metrics dashboards with zero-configuration auto-discovery
- [Prometheus](https://prometheus.io/) — open-source monitoring system and time series database with a powerful query language
- [Uptime Kuma](https://uptime.kuma.pet/) — self-hosted, modern uptime monitoring tool with a clean UI
- [Zabbix](https://www.zabbix.com/) — enterprise-class network and application monitoring with alerting

## Log Management

- [Fluentd](https://www.fluentd.org/) — open-source data collector for unified logging layer
- [GoAccess](https://goaccess.io/) — real-time web log analyzer and interactive viewer in the terminal
- [lnav](https://lnav.org/) — advanced log file navigator that merges, colorizes, and queries logs with SQL
- [Loki](https://grafana.com/oss/loki/) — horizontally-scalable, highly-available log aggregation system inspired by Prometheus
